# Screenshot nella Galleria del tablet

La guida aggiornata è nel **[README del progetto](../README.md)**, che descrive:

- attivazione congiunta di appunti e screenshot tramite KDE Connect;
- scorciatoia normale ⌘⇧4 e ritorno alla Scrivania quando l’app è spenta;
- cache `Incoming` / `Sent` e cancellazione automatica delle nuove copie tracciate;
- limite della conferma di invio KDE, diagnosi, arresto e rimozione.

Il README sostituisce le precedenti istruzioni relative a Xiaomi Interconnectivity e alla scorciatoia Automator.
